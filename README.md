# WRST Gate — MVP

Локальное приложение Python / PySide6 для Windows 11. Правильный ответ на задачу даёт 20 минут игрового времени; награда настраивается от 1 до 240 минут. Встроены 35 авторских тренировочных задач по семи темам профильного ЕГЭ. Это базовые задачи, а не полный вариант экзамена.

## Установка на Windows 11

Нужен 64-битный Python 3.11 или 3.12 с python.org. Распакуйте проект в постоянную папку. В PowerShell, находясь в этой папке:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

При уже установленном PySide6 и psutil приложение запускается командой `python main.py`. Права администратора не требуются.

1. На странице «Мои игры / Настройки» добавьте настоящий исполняемый файл игры через диалог выбора `.exe`. Для игр, использующих отдельный launcher, выбирайте исполняемый файл самой игры.
2. Решайте задачи. Принимаются числовые ответы с точкой или запятой; абсолютная погрешность — 0,000001. Дробь `1/4` вводите как `0,25`. Ввод не исполняется как Python-код.
3. При запуске одной или нескольких игр баланс списывается один раз. Сворачивание игры не останавливает списание.
4. При нулевом балансе контролируемые процессы завершаются. Перед этим сохраните прогресс игры: принудительное завершение может потерять несохранённую игру.
5. После всех 35 задач можно вручную начать новое прохождение. Повторное начисление той же задачи в одном прохождении исключено, в том числе после перезапуска.

Закрытие окна сворачивает его в трей. Двойной щелчок по значку открывает окно. В меню трея доступны открытие, отключение контроля и полный выход. Если трей недоступен, закрытие окна завершает приложение. Автозапуск включается в настройках и использует только пользовательский ключ реестра `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. После перемещения программы переключите автозапуск заново.

## Данные и восстановление доступа

Данные Windows: `%LOCALAPPDATA%\WRST Gate\gate.sqlite3`; журнал ошибок рядом, `errors.log`, с ротацией. Под Linux для тестов: `~/.local/share/WRST Gate`. Данные не записываются в папку установки. Для резервной копии полностью закройте приложение и скопируйте папку данных.

Контроль отключается флажком в настройках, из меню трея или командой:

```powershell
.\.venv\Scripts\python.exe main.py --disable-control
```

Команда работает даже без PySide6 и отключает также уже работающий монитор при следующем опросе. После восстановления откройте настройки, чтобы включить контроль. Приложение всегда можно завершить обычным способом через диспетчер задач. Если повреждена сама SQLite: завершите WRST Gate, сохраните копию папки данных, переименуйте её и запустите заново; создастся пустая база, прежний баланс автоматически не восстановится.

## Сборка EXE на Windows

Собирать Windows EXE нужно на Windows, в том же виртуальном окружении:

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --windowed --onedir --name WRSTGate --add-data "assets;assets" main.py
```

Запуск: `dist\WRSTGate\WRSTGate.exe`. Передавайте всю папку `dist\WRSTGate`, не только EXE. Для восстановления: `dist\WRSTGate\WRSTGate.exe --disable-control`. Окно консоли при этом не открывается, настройка сохраняется в базе. Подпись EXE и установщик не входят в MVP.

## Архитектура

- `main.py` — пользовательская папка, журнал, блокировка второго экземпляра через QLockFile, запуск приложения и аварийное отключение.
- `ui/window.py` — тёмный интерфейс, формулы Unicode, задачи, настройки, трей; монитор работает в QThread, обновления идут сигналами в GUI.

- `core/time_wallet.py` — баланс с точностью до миллисекунды, ограничение списания остатком и атомарная награда.

## 1. Основная концепция

Программа работает по принципу компьютерного клуба.

Вместо денег пользователь пополняет баланс игрового времени правильными ответами на математические задачи.

**Курс MVP: 1 правильно решённая задача = 20 минут игрового времени.**

Например:
- 3 задачи = 60 минут.
- 6 задач = 120 минут.
- 12 задач = 240 минут.

Время можно накапливать без ограничения. Неиспользованный баланс сохраняется между запусками приложения и перезагрузками компьютера.

## 2. Контроль игр

Приложение предназначено для Windows 11.

Реализуй следующие функции:

- Пользователь самостоятельно добавляет игры в список контролируемых приложений, выбирая `.exe` через файловый диалог.
- Программа в фоне отслеживает процессы выбранных игр.
- Пока хотя бы одна контролируемая игра запущена, игровой баланс уменьшается в реальном времени.
- Если запущено несколько контролируемых игр одновременно, время списывается только один раз.
- Сворачивание игры не останавливает таймер.
- Если все контролируемые игры закрыты, списание прекращается.
- При нулевом балансе программа автоматически завершает процессы контролируемых игр и продолжает блокировать повторный запуск.
- Когда баланс пополнен, запуск игр снова разрешён.
- За 10, 5 и 1 минуту до окончания баланса показываются уведомления.
- При запуске самого WRST Gate баланс и список игр восстанавливаются.

Не изменяй файлы игр, не внедряй код в процессы и не взаимодействуй с античитами. Используй обычные Windows API и мониторинг процессов.

Добавь безопасное ручное отключение контроля в настройках. Приложение не должно блокировать систему целиком, препятствовать завершению своей работы или мешать запуску важных системных программ.

- Учёт времени должен использовать монотонные часы, чтобы изменение системного времени не давало бесплатно игровые минуты.
- При обнаружении игры процесс должен определяться по надёжному пути к исполняемому файлу, а не только по имени.
- Избегай завершения одноимённых посторонних процессов.
- Корректно обрабатывай отсутствие доступа к процессу.
- Если приложение было выключено, не списывай время за период, когда оно не работало.
- Не допускай отрицательного баланса.
- Не требуй прав администратора без необходимости.
- Реализуй журнал ошибок.
- Предусмотри возможность ручного восстановления доступа при сбоях.
- Все данные храни в пользовательской директории приложения, а не в папке установки.

## 8. Тестирование

**Приоритет — работающий MVP, а не идеальная архитектура.**

Не добавляй облачные сервисы, аккаунты, авторизацию, платёжные системы, искусственный интеллект и дополнительные функции без необходимости.

Начинай реализацию прямо сейчас.
`assets/tasks.json` — расширяемый локальный банк, числовая проверка, прохождения.
- `storage/database.py` — SQLite WAL / synchronous FULL, транзакции BEGIN IMMEDIATE, уникальность (прохождение, ID задачи), история начислений и списаний, настройки и игры. База сериализует доступ из GUI и монитора.

Для расширения банка добавьте объект с уникальным `id`, `topic`, `text`, числовым `answer` в `assets/tasks.json`. Не меняйте ID уже существующих задач: они используются в истории. Ответы находятся локально; это приложение для самоконтроля, а не защита от владельца компьютера.

## Ограничения MVP

Контроль действует только пока запущен WRST Gate. Он не мешает выходу, не блокирует систему, не внедряется в процессы и не взаимодействует с античитами. Системная папка Windows и собственный исполняемый файл не принимаются в список игр. Программы с более высокими правами могут быть недоступны; приложение сообщает об этом и не запрашивает повышение прав.

Опрос дискретный: первый запуск обнаруживается с задержкой примерно до 250 мс плюс длительность обхода процессов. Короткий запуск между опросами может быть пропущен. При аварии возможен неоплаченный интервал до очередной транзакции; уже записанный баланс не увеличивается и не сбрасывается. Во время выключенного приложения время не списывается. Неограниченное накопление ограничено только размером INTEGER в SQLite (практически недостижимым).

На Windows используются обычные средства psutil. Обработка процессов соответствует [документации psutil](https://psutil.readthedocs.io/stable/); трей реализован через [QSystemTrayIcon](https://doc.qt.io/qtforpython-6.8/PySide6/QtWidgets/QSystemTrayIcon.html).
