# Отчёт о проверках — 24 октября 2026

Среда: Linux, Python 3.14, PySide6 6.12.0, установленный psutil. PySide6 установлен в отдельное тестовое виртуальное окружение. Windows и реальные игры в этой среде отсутствуют.

Команда из папки проекта:

```text
QT_QPA_PLATFORM=offscreen python -m unittest discover -s tests -v
Ran 13 tests — OK
```

Реально проверено:

1. Начисление 20 минут.
2. Списание и ограничение остатком, запрет отрицательной суммы списания.
3. Сохранение баланса, списка игр и настроек при повторном открытии базы.
4. Защита от повторной награды: конкурентные вызовы из восьми потоков и отдельное подключение SQLite.
5. Блокировка при нулевом балансе, повторная блокировка, разрешение после награды.
6. Несколько процессов списывают время один раз; закрытие всех останавливает списание.
7. Перезапуск монитора не списывает время отсутствия приложения.
8. Совпадение полного пути: одноимённый процесс по другому пути не завершается.
9. AccessDenied не завершает монитор; ручное отключение не блокирует процессы.
10. Пороговое уведомление и отсутствие его повторения при следующем опросе.
11. Все 35 задач: начисление, защита от дубликата, завершение и новое прохождение.
12. Проверка чисел с запятой и погрешностью, отклонение NaN, Infinity, кода и неподдерживаемых выражений.
13. GUI: создание окна, переключение всех страниц, неверный и правильный ответ, изменение награды, отключение контроля, завершение QThread.

Интеграционный тест блокировки использует отдельную копию `/bin/sleep` с уникальным путём `safe-game.exe` во временной папке. Запущенный дочерний процесс действительно завершён монитором при нулевом балансе. Реальные игры и посторонние процессы не используются. Этот тест пропускается на Windows, где `/bin/sleep` отсутствует; остальные тесты доступны.

Дополнительно: выполнен фактический запуск функции входа `main.py` с временной папкой данных, цикл событий Qt работал 700 мс, фоновый монитор остановлен корректно. Скриншоты трёх страниц получены через Qt offscreen; страницы задач и настроек визуально просмотрены. Плагин offscreen сообщает об отсутствии системного трея и поддержке изменения размеров; это ожидаемые ограничения тестового окружения.

Не проверены: запуск на Windows 11, запись в реестр автозапуска, настоящие уведомления и поведение трея Windows, права доступа к реальным игровым процессам, PyInstaller EXE. Windows EXE здесь не собирался. Инструкции сборки приведены в README. Проверка восстановления SQLite после принудительного отключения питания не выполнялась; используются WAL, synchronous FULL и атомарные транзакции.
